# AI-Powered Software Engineer

This repository tracks my practical work through the AI-Powered Software Engineer course.

The goal is not only to learn AI-assisted development, but to build the engineering habits needed to ship reliable software:

- Test-Driven Development
- pytest
- unit, integration, and end-to-end testing
- Continuous Integration
- GitHub Actions
- design patterns
- software architecture patterns
- AI-assisted development with engineering control

## Course Sections

1. Test-Driven Development
2. Design Patterns
3. Software Architecture Patterns
4. Vibe Engineering

Each lesson follows this structure:
